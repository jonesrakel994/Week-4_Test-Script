# Week 4: Usability Testing Deliverable

## Project Overview
Test script, Test sessions, and Observation log submission for Week 4.

## TEST SCRIPT
Task 1 – Attempt to add a plant to Garden.
Task 2 – Attempt to remove a plant from Garden.
Task 3 – Attempt to return to the home page.

## TEST SESSION NOTES / OBSERVATION LOG
User 1 – Boluwatife
(Task - Attempt to add a plant to Garden.)
The user clicked on the “Add plant” button as that was the easiest and most obvious call to action on the page. The button navigated the user to the next page which displayed the available plants to be added to the garden. Again, the user was able to easily figure out how to add plants to the garden as a result of the small plus button at the edge of the plant card. This navigated the user to the “New Plant” page where the details of the plant to be added are fully displayed. The user clicked the “Save Plant” button which triggered a pop-up bar at the top of the page, displaying that the plant was saved successfully. After this, the user got stuck and was unable to exit the page and navigate to a new page to view the now populated Garden. The user’s first instincts to get out of the page was to try every button on the lower Nav bar. Clicking each of these buttons didn’t give the user a desired result and this led to palpable frustration from the user.

User 2 – Fifehan
(Task - Attempt to remove a plant from Garden.)
The user was able to easily figure out that the small minus button at the edge of the plant card was the “delete plant” button and instantly clicked on it. Clicking on the button immediately triggered a pop-up with two options; Cancel & Remove. The user clicked on the “Remove” button, expecting it to delete the selected plant. User 2 had no issues carrying out the task but expected a more defined ending to complete the task.

User 3 – Olayemi
(Task - Attempt to return to the home page.)
The user was taken to the populated garden page and tasked to figure out how to return to the home page. User 3 was able to spot the “Back” button in seconds and easily clicked on it on each page till she was able to return to the Home page. 
User 3 felt the most satisfaction with her task of all 3 users.
